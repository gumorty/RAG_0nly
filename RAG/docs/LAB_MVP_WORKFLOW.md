# Lab MVP Workflow

## 每周会议流程

1. 创建 `实验室知识库`。
2. 每个人上传本周资料，填写作者、项目、会议日期和标签。
3. 系统异步解析和索引，状态变为 `可检索` 后进入问答。
4. 查看知识库质量概览，重点检查失败文档、chunk 数异常、质量告警和周报信号。
5. 查看会议摘要，先快速扫一遍系统抽取的进展、风险、下周计划和决策。
6. 会议中可提问：
   - 本周每个人分别完成了什么？
   - 某项目当前风险是什么？
   - 上周提出的问题这周是否解决？
   - 某个实验指标在哪份资料里出现过？
7. 回答必须查看引用来源，发现错误时点击反馈。
8. 每周沉淀 10-20 个真实问题到评估集，用于后续策略优化。
9. 每次调整 chunk、topK、rerank 或上下文窗口后，使用策略对比接口验证是否真的提升。

## 推荐元数据

- author: 汇报人
- project: 项目名
- meeting_date: 会议日期，例如 `2026-06-09`
- tags: 逗号分隔，例如 `无人机,周报,实验`
- acl: 默认使用上传者用户 ID；共享资料可填 `public`，企业场景可填用户 ID、邮箱或角色。

## 第一批评估问题

- 最近一次会议中，每个人的核心进展是什么？
- 某项目有哪些未解决风险？
- 哪些工作依赖其他成员？
- 某个模型、数据集或实验设备在哪些资料中出现过？
- 本周计划和上周计划相比有哪些变化？
