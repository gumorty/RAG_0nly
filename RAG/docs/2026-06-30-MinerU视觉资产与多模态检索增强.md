# 2026-06-30 MinerU 视觉资产与多模态检索增强

## 背景

当前系统已经使用 MinerU 处理 PDF、图片、扫描件和复杂表格。之前的问题是：系统主要读取 MinerU 的 `full.md`，对 zip 里的图片、版面 JSON、结构化结果利用不足；图表/扫描件问题只能依赖 OCR 文本、图题和目录，无法形成稳定的图片级召回。

本轮目标不是替换 RAGFlow，而是在 RAGFlow 主链路旁增加一个“本地视觉资产缓存”，让 MinerU 解析出的图片和版面产物进入可检索、可评估、可删除的治理链路。

## 新增链路

```text
上传 PDF/图片/扫描件
  -> MinerU OCR / VLM / 表格解析
  -> 下载 MinerU result zip
  -> 读取 full.md
  -> 提取 zip 中图片 / layout JSON / table JSON
  -> 生成 Markdown 视觉资产检索索引
  -> 上传增强 Markdown 到 RAGFlow
  -> 图片资产写入 MinIO
  -> 可选调用 Qwen/Qwen3-VL-Embedding-8B 生成本地视觉向量
  -> 写入 visual_asset_cache
  -> 问答时与 RAGFlow retrieval、本地 BM25 一起做 RRF 融合
```

## 关键实现

### 1. MinerU zip 深解析

修改文件：

- `backend/app/services/mineru.py`

新增能力：

- 从 MinerU zip 中读取图片文件。
- 从 JSON 文件中递归抽取 caption、text、content、tables、figures、images、cells 等结构化文本。
- 限制最大图片数量、图片大小和 JSON 文本长度，避免大文件撑爆内存。

### 2. 视觉资产索引

新增文件：

- `backend/app/services/visual_assets.py`

新增能力：

- 为图片生成 `# 视觉资产检索索引`。
- 从文件名、Markdown 图片引用和邻近文本中推断页码、图号、图题。
- 将 MinerU JSON 中的版面/图表/表格文本追加到 Markdown 中，使 RAGFlow 也能检索到这些结构化线索。

### 3. 本地视觉向量缓存

修改文件：

- `backend/app/models/entities.py`
- `backend/app/api/routes.py`

新增表：

- `visual_asset_cache`

主要字段：

- `collection_id`
- `document_id`
- `asset_id`
- `asset_type`
- `object_key`
- `source_path`
- `page_no`
- `figure_no`
- `caption`
- `context`
- `embedding`
- `embedding_model`

删除知识库或删除文档时，会同步删除视觉资产缓存和 MinIO 中的图片对象，避免记忆污染。

### 4. 多模态向量模型

配置项：

```env
VISUAL_ASSET_INDEX_ENABLED=true
VISUAL_EMBEDDING_ENABLED=true
VISUAL_EMBEDDING_BASE_URL=https://api.siliconflow.cn/v1
VISUAL_EMBEDDING_MODEL=Qwen/Qwen3-VL-Embedding-8B
VISUAL_EMBEDDING_DIMENSIONS=1024
```

说明：

- `Qwen/Qwen3-VL-Embedding-8B` 是多模态向量模型，可用于图片/文本同空间检索。
- 它不是直接输出图片描述的聊天模型，所以当前用于“图片资产召回”，不是完整图像问答。
- 如果视觉向量 API 调用失败，系统会记录 `embedding_error`，但不会中断文档入库。

### 5. 问答融合

修改文件：

- `backend/app/services/chat.py`

新增通道：

- `local_visual_embedding`

触发条件：

- 问题包含图、图片、图表、扫描件、OCR、页面、页码、截图、图中等视觉意图词。

融合方式：

- 视觉资产向量召回结果作为一个 RRF channel，与 RAGFlow semantic/keyword、query rewrite、本地 BM25 cache 一起融合。

## 当前能力边界

已增强：

- 图片/扫描件资产可入 MinIO 管理。
- 图片资产有本地多模态向量，可参与文本问题召回。
- MinerU JSON 中的结构化文本会进入 Markdown 和 RAGFlow 索引。
- 图号、页码、图题、邻近文本进入检索链路。

仍未完成：

- 尚未把图片坐标、页面截图、高亮框直接展示到前端。
- 尚未接入真正的视觉生成模型来输出“图中每个柱状/曲线数值”的自然语言解释。
- 旧文档需要重新上传或后续做“重建视觉资产索引”任务，才能拥有新的视觉缓存。
