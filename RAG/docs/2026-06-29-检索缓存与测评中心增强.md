# 2026-06-29 检索缓存与测评中心增强

## 本次问题根因

用户提问后转圈并消失，不是前端单纯卡顿，而是后端流式问答收到 RAGFlow retrieval 异常后只发出了 `error` 事件；前端只处理 `answer`，忽略 `error`，并且 `onError` 只会修改最后一条 assistant 消息。当最后一条是 user 消息时，界面不会落任何提示。

Docker 日志中的关键异常为 RAGFlow 查询阶段调用 embedding 失败：

```text
EmbeddingError / BadRequestError
AllocationQuota.FreeTierOnly
The free quota has been exhausted.
```

这说明 RAGFlow 在 query embedding 阶段因为第三方 embedding 模型额度不足而失败。

## 已完成改动

1. 新增本地 `retrieval_chunk_cache` 表，同步 RAGFlow chunk 文本、RAGFlow doc/chunk id、页码、标题、分数与原始元数据。
2. 新增 `domain_lexicon_terms` 表，用于后续维护同义词、缩写、实体别名、停用词。
3. 新增企业级测评表：
   - `evaluation_datasets`
   - `evaluation_cases`
   - `evaluation_runs`
   - `evaluation_results`
4. 文档解析完成或刷新文档状态时，同步 RAGFlow `/chunks` 到本地 cache。
5. 问答检索链路改为：
   - RAGFlow semantic / keyword / rewrite / table / section / title 多通道检索
   - 单个 RAGFlow 通道失败不再拖垮整次问答
   - 本地 BM25 cache 通道加入 RRF 融合
   - RAGFlow 全部失败时，降级到本地 BM25 cache
6. 前端流式问答支持 `error` 事件可见化，不再吞问题。
7. 前端新增测评中心入口，可创建测评集、运行测评、查看 Recall/MRR/NDCG/faithfulness/引用可读率和失败样例。
