# 当前问题修复与启动记录

记录时间：2026-06-27

## 本次重点修复

### 1. RAGFlow 文档归属与解析错误

修复了 `RAGFlow dataset creation failed: The dataset ... doesn't own parsed file` 一类问题。

处理方式：

- 上传到 RAGFlow 后校验 `ragflow_document_id` 是否属于当前 dataset。
- 如果 RAGFlow 返回的文档不属于当前 dataset，则使用唯一前缀重新上传，避免不同 dataset 间复用到错误文件。
- 重新解析前也会检查文档归属，不属于当前 dataset 时返回明确的 `409`，不再继续触发 RAGFlow 报错。

### 2. RAGFlow 检索绕过本地 ACL

修复了 RAGFlow retrieval 返回全 dataset chunks 后可能绕过本地文档 ACL 的问题。

处理方式：

- RAGFlow retrieval 后按本地可读文档集合过滤 chunks。
- 被过滤前后的数量写入 retrieval trace，便于审计和复盘。
- RAGFlow chat completions fallback 只在 ACL 可以安全认为“全部可读”时启用，否则走 retrieval-only + ACL 过滤链路。

### 3. 前端暴露 Admin API Key

移除了 `NEXT_PUBLIC_API_KEY` 和前端所有 `X-API-Key` 请求头。

当前浏览器侧只使用：

```text
Authorization: Bearer <access_token>
```

Admin API Key 只应留给服务间调用或运维脚本。

### 4. 注册权限越权

修复公开注册时第二个用户仍可能成为 admin 的 off-by-one 问题。

当前策略：

- 只有数据库中完全没有用户时，第一个注册用户才会成为 admin。
- 后续公开注册受 `PUBLIC_REGISTRATION_ENABLED` 控制。
- 生产环境建议设置为 `false`。

### 5. CORS 与安全配置

新增：

- `CORS_ALLOWED_ORIGINS`
- `MAX_UPLOAD_SIZE_MB`
- `MAX_ZIP_UPLOAD_SIZE_MB`
- `ALLOW_PRIVATE_URL_INGEST`

修复点：

- 不再使用 `allow_origins=["*"]` + `allow_credentials=True`。
- URL 导入增加 SSRF 防护，默认禁止 localhost、内网、链路本地地址和云元数据地址。
- 上传文件和 ZIP 有大小限制。
- 上传文件名和 ZIP 内部路径会做安全清洗。

### 6. 文档删除与 RAGFlow 索引一致性

删除文档时会同步删除 RAGFlow 中的文档/索引。

如果 RAGFlow 删除失败且不是“远端已不存在”，接口会返回错误，不会悄悄删除本地记录，避免本地和 RAGFlow 索引不一致。

### 7. RAGFlow 异常可读化

`RagFlowClient._request()` 统一包装 HTTP 状态错误、网络错误和非 JSON 响应为 `RagFlowError`，上层接口能返回更可读的错误信息。

### 8. README 与部署文档乱码

重写了根目录 `README.md` 和 `docs/RAGFlow集成部署说明.md`，统一为当前真实链路和端口。

### 9. 会话记录从“最近 20 条”升级为真实会话恢复

修复了前端只调用 `answers?limit=20` 导致聊天记录不完整的问题。

处理方式：

- `answers` 表新增 `user_id` 和 `session_id`。
- `/api/chat` 和 `/api/chat/stream` 会保存当前用户与当前会话。
- `/collections/{collection_id}/answers` 支持按 `session_id` 查询，默认上限提高到 500，最大 1000。
- 前端为每个知识库生成稳定的本地会话 ID，并在提问和恢复记录时传给后端。
- 为兼容旧数据，查询当前会话时会同时包含 `session_id IS NULL` 的历史记录，避免升级后旧聊天突然消失。

### 10. 表格证据误读修复

修复了“新疆有哪些地区在旺季期间有浮动，浮动了多少”这类问题中，模型把其他地区的旺季浮动标准错误归到新疆的问题。

根因：

- RAGFlow 返回的表格证据是压扁的 HTML table。
- 同一张跨省表里青海、海南、西藏等地区有旺季字段，而新疆行没有旺季字段。
- 模型在长表格邻近文本中容易把相邻行字段错误归因到新疆。

处理方式：

- 后端把 RAGFlow HTML table 转成可读的 `列 | 列 | 列` 行文本。
- 进入模型前按当前问题做 query-aware 表格行聚焦，例如问题问“新疆”，只保留新疆/乌鲁木齐/石河子等相关行。
- 不再自动携带表格相邻行，避免把青海、海南、西藏的旺季字段混入新疆证据。
- Prompt 增加强约束：表格证据只能使用同一行或明确连接单元格中的值，不得从相邻地区推断。
- 新增回归测试 `test_chat_evidence.py` 覆盖该场景。
