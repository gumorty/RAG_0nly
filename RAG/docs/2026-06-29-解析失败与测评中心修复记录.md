# 2026-06-29 解析失败与测评中心修复记录

## 根因

本次 PDF 上传后大量失败的直接原因不是 MinerU 解析失败，而是 RAGFlow 的旧知识库仍绑定旧 Embedding 模型：

- RAGFlow tenant 默认 Embedding 已经切换为 SiliconFlow。
- 但 RAGFlow `knowledgebase` 表中的旧 dataset 仍保存旧 `embd_id`。
- 文档解析完成后，RAGFlow 在绑定 Embedding 模型阶段继续调用旧模型，返回额度耗尽错误，任务被标记为失败。

## 修复

1. 后端新增 RAGFlow dataset Embedding 自愈：
   - `RagFlowClient.ensure_dataset_embedding(dataset_id)`
   - 创建知识库后立即校验。
   - 旧知识库再次上传文档前也会校验并更新 dataset 级 Embedding。

2. 本机 RAGFlow 数据已同步修复：
   - 管理员 tenant 下 12 个 knowledgebase 已统一切换到 `Qwen/Qwen3-Embedding-8B@siliconflow@OpenAI-API-Compatible`。

3. 失败文档已重新触发解析：
   - `P020241210548865982463.pdf`：重新生成 48 个 chunk。
   - `W020171101487736565541.pdf`：重新生成 5 个 chunk。

4. 前端文档治理面板优化：
   - 长错误日志不再直接撑满卡片。
   - 显示可操作摘要，原始日志折叠保留。

5. 测评中心优化：
   - 恢复测评集列表、创建、运行入口。
   - 空测评集运行返回 `skipped` 和明确提示，不再表现为异常。
